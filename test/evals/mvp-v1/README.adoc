= Benchmark suite mvp-v1

[[mvp-v1-summary]]
== Summary

`mvp-v1` is Kodo's initial role-model evaluation suite. It contains 10 search,
10 review, and 10 implementation tasks built from purpose-made fixtures. Hidden
implementation files and checks are materialized only after the evaluated agent
finishes its implementation attempt.

The suite artifact is link:suite.json[`suite.json`]. Its fingerprint, accepted
result, benchmark standard, and regression thresholds are recorded in
link:criteria.json[`criteria.json`]. Shared criterion definitions and
improvement targets come from `quality-v1` in the
link:../criteria.json[top-level benchmark catalog].

[[mvp-v1-accepted-baseline]]
== Accepted baseline

The accepted result is
link:results/balanced-profile-v8-2026-08-25.json[`balanced-profile-v8-2026-08-25.json`].
It evaluates `openai:gpt-4o-mini` with no reasoning for the primary, search, and
review roles using primary contract v6 and toolset `workspace-v5`, search
contract v3 and toolset `read-only-v1`, and review contract v4 and toolset
`read-only-v1`.

The suite-specific regression floors preserve this accepted result's quality
while the shared targets identify remaining work. In particular, search
evidence citation and final-review precision remain below their `quality-v1`
targets and should improve without regressing implementation correctness,
scope, harness reliability, cost, or latency.

[[mvp-v1-gpt-5-6-candidates]]
== GPT-5.6 candidates

Recorded OpenAI API comparisons cover Terra primary/search, Sol primary with
Terra search, and Sol primary/search while retaining `gpt-4o-mini` for the
structured review role. Terra achieved complete search file and evidence recall.
Sol primary reached 100% public and 90% hidden implementation success. Sol did
not improve search over Terra and increased both cost and latency.

The Sol-primary/Terra-search mapping is the strongest observed quality profile,
but it costs substantially more and exceeds the suite's p95 latency regression
threshold. It is therefore evidence for a future quality-oriented profile, not
a replacement for the accepted balanced baseline. The detailed comparison and
reasoning-configuration caveat are recorded in
link:../../../docs/evaluations.md[the evaluation analysis].

Terra and Sol cannot currently be assigned to review through the normal Kodo
capability boundary because the bundled model catalog does not declare JSON
Schema support for them. ChatGPT-subscription evaluation additionally requires
the OpenAI Codex OAuth device authorization and account flow, which is not part
of this suite iteration.
